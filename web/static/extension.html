Install it

  1. Unzip the download. You'll get a folder called coreprop-extension. Keep it somewhere permanent, because Chrome loads it from this location every time it starts, so don't leave it in Downloads and delete it later.
  2. Open chrome://extensions in a new tab.
  3. Turn on Developer mode (toggle, top right).
  4. Click Load unpacked and select the coreprop-extension folder.
  5. Come back here and reload this page. The banner above should turn green.
Developer mode is required because this extension isn't distributed through the Chrome Web Store. Chrome will show a "Disable developer mode extensions" prompt each time it launches. Dismissing it is fine; the extension keeps working.

How to use it

  1. Sign in to PrizePicks in the same browser, at least once.
  2. On CoreProp's Backtest page, find a pending slip and click Place on PrizePicks.
  3. A PrizePicks tab opens. A CoreProp panel appears bottom-left and works through the legs one at a time, ticking each one off as PrizePicks confirms it.
  4. Check the entry type it tells you to set (Power or Flex), type your stake, and submit.
The extension never enters a stake and never submits a wager. It only selects picks; everything involving money stays with you.

If it doesn't work

The panel says "Sign in to PrizePicks." You're signed out or PrizePicks is asking for a location check. Finish that, and staging continues automatically.

The panel says a security check is showing. PrizePicks runs bot protection that occasionally challenges a freshly opened tab. Complete it and press Retry; your slip is still saved.

A leg says "line moved". PrizePicks no longer offers the number your slip was logged at. The panel shows what's on the board now. Add it by hand if you still want it.

A leg says "N matching cards". Two cards on the board fit the same player, prop and line. CoreProp won't guess between them; add that one manually.

Nothing happens at all. Check the banner at the top of this page. If it's not green, Chrome didn't load the extension. Re-do Load unpacked, then reload.
